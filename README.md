# CITL Smart System — Operational Repairs

نسخة إصلاح التشغيل مع الحفاظ على الهوية وطريقة العرض الحالية.

ابدأ من **START-HERE-AR.md** لخطوات التشغيل، **REPAIRS.md** لما تغير وحدود التحقق، و**NEXT-STAGE-CODEX.md** لتكليف تطوير الشاشات وQR لاحقاً.

الملف الوحيد المطلوب لتحديث القاعدة: **SUPABASE-REPAIR.sql** كاملاً، بعد نسخة احتياطية وتجربة على نسخة من القاعدة الفعلية. لا تحتاج حذف الجداول أو إعادة استيراد جدول الترم لتثبيت الإصلاح.

اختبارات التطوير موجودة في tests/ ولا تُشغّل بياناتها على Supabase الإنتاجي.
